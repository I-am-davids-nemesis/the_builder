# Series tension ledger

Book 1 closes the small, concrete questions and leaves every root conflict open.

**Pacing rule of thumb:** per book, resolve about one thread outright, advance two or three, and open one new one. That keeps the ledger roughly the same size while the stakes rise.

When a draft resolves or opens a thread, update this file in the same change.
