# The Builder

A retelling of *The Builder* (P.S. Power), drafted in two narrative modes. Migrated from `the_builder` @ 3bfa467 on 2026-10-16.

- `manuscript/`: one folder per chapter; each scene as `NN-scene.camera.md` and `NN-scene.rotating-third.md`.
- `outline/`: `book-plan.md`, and per chapter a `_chapter.md` plus one beat file per scene.
- `codex/`: characters, locations and reference notes.

See `AGENTS.md` for the conventions.
