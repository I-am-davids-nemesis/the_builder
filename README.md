# The Builder

A retelling of *The Builder* (P.S. Power), drafted in rotating close third (an earlier camera-mode draft is on the `camera` branch). Migrated from `the_builder` @ 3bfa467 on 2026-10-16.

- `manuscript/`: one folder per chapter; each scene as `NN-scene.rotating-third.md`. The camera-mode drafts (chapter 1 to chapter 5, scene 3) are on the `camera` branch.
- `outline/`: `book-plan.md`, and per chapter a `_chapter.md` plus one beat file per scene.
- `codex/`: characters, locations and reference notes.

See `AGENTS.md` for the conventions.
